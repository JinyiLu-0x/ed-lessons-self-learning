# ED Lessons Self-Learning

一个面向所有课程的 Codex Skill：严格依据用户提供的 Ed、Moodle、lesson、lab、题目与答案、视频、slides 与课程说明制作中文自学笔记，并保留关键 English terms。

## 本次更新

- 新增题目知识点模式：把用户提供的题目与答案提炼成简洁、可直接复制的知识点笔记。
- 多道题合并重复概念，不按题号逐题复述。
- 重要 English terms 第一次出现时补充准确、简短的中文解释；代码示例只保留理解规则所需的部分。
- 容易混淆的概念使用并列对比，例如 `declaration` 与 `initialisation`。
- 固定常见术语译法：`primitive type` 为“基本数据类型”、`literal` 为“字面量”、`declaration` 为“声明”、`initialisation` 为“初始化”。
- 题目与答案矛盾时标记“答案待确认”，不把冲突内容写成确定知识点。
- 新增独立的多段视频模式：一个视频对应一个 `Part`，按原顺序使用 `1.1`、`1.2`、`2.1` 等编号。
- 重写 slides 模式：把整套 slide deck 视为一个整体，按真实主题变化分节，不再逐页机械翻译，也不平铺成没有层级的长文。
- Slides 输出固定包含“这份 slides 在说什么”、主题小节与“Slides 小结”。
- 章节、Part、标题和正文之间保留一个空行，方便直接复制到 Markdown 或 Obsidian。
- 中文为主，保留 `class`、`object`、`compile`、`execute` 等关键英语术语。
- Assessment、出勤、提交、软件要求、AI 规则和教师明确提醒不得遗漏；普通欢迎语和人员名单可以压缩。
- 增加上下文隔离：不混入其他对话、旧命令、端口、文件或 schema，并忽略审批文字、模型名称、按钮等界面残留。
- 对缺页、截断、听不清和关键图片缺失进行明确标注，不自行猜测。
- 教程示例改用占位符，不绑定具体课程、目录或文件名，可跨学期、跨课程复用。

## 支持的材料

- Ed lesson、Moodle 内容与课程通知
- Lab、tutorial、workshop 与环境配置教程
- Quiz、练习题、选择题、判断题、简答题或代码题及其答案
- 多段视频、视频摘要与视频转写
- Lecture slides、PPT、slide deck、PDF 讲义与 slides 截图
- Week Overview、学习目标、课堂安排与一般说明文字
- Terminal 输出与教程进度检查

## 五种输出模式

### 1. 教程型

用于安装、配置、运行、提交或其他需要实际跟做的材料。

1. **总览**：说明任务和用途。
2. **任务拆解**：标记已完成、未完成或无法确认。
3. **步骤细化**：从未完成部分继续，一条可复制命令配一行解释。

### 2. 多段视频

每段视频单独整理为一个 `Part`：

- 用 2–4 句话说明这段视频在讲什么。
- 根据真实主题变化拆成 `1.1`、`1.2` 等小节。
- 解释“是什么意思”“为什么重要”，并保留规则、示例、步骤和教师提醒。
- 每个 Part 末尾用 3–6 条短句总结。

### 3. Slides

整套 slides 使用统一结构：

- `# Week / Lecture：Slides 原标题`
- `## 1. 这份 slides 在说什么`
- `## 1.1 小节主题`、`## 1.2 小节主题`……
- `## Slides 小结`

连续多页属于同一主题时合并；只有主题真正变化时才增加小节。技术概念、流程图、架构图和对比关系需要讲清楚，行政内容保持简洁。

### 4. 题目知识点

题目与答案整理为不重复的核心知识点：

```markdown
**English term（中文解释）**
`code example`：一句话说明含义、用途或规则。
```

- 每个知识点尽量一行讲清楚。
- 多题涉及同一概念时只保留一次。
- 不逐字翻译全部英文，不添加题外扩展或总结段落。
- 容易混淆的概念使用相邻条目并列对比。

### 5. 一般文字说明

按原章节与顺序整理为：

1. **这段在说什么**
2. **重点拆解**
3. **小结**

## 使用示例

### 整理 slides

```text
使用 $ed-lessons-self-learning。
请整理这份 lecture slides：中文为主，保留关键 English terms，
按真实主题变化分节，章节之间空一行。
```

### 整理多段视频

```text
使用 $ed-lessons-self-learning。
下面是多段视频内容。每段视频分别作为一个 Part，
严格按视频顺序整理，不要擅自合并。
```

### 整理题目与答案

```text
使用 $ed-lessons-self-learning。
请把下面的题目与答案提炼成不重复的知识点笔记；
保留重要 English terms，代码示例保持短小，不要逐题复述。
```

### 跟做教程

```text
使用 $ed-lessons-self-learning。
下面是课程教程和 Terminal 输出。前两步已经完成，
请判断进度并从下一项未完成任务继续。
```

## 行为边界

- 只依据当前提供的课程材料，不自行添加延伸知识。
- 不擅自选择目录、Webroot、端口、软件或替代方案。
- 不重复安排已经完成的任务。
- 不把 slides 中出现的命令误判为整套教程。
- 不遗漏重要定义、规则、示例、操作步骤、教师提醒和易混淆区别。
- 无法确认的内容直接标注，不猜测。
